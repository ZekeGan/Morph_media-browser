## 現行閱讀器與資訊配置

漫畫屬性及資訊 CELL 保持獨立，僅共用 [統一媒體工作區](MEDIA_WORKSPACE.md#統一媒體工作區) 的大視窗外框與同資料夾圖片佇列。大視窗預設覆蓋應用程式，下面的系統全螢幕是明確啟用的沉浸操作，不能在開啟檢視器時自動觸發；一般圖片需明確選擇漫畫閱讀模式，不自動改寫分類。

- 大量圖片沿用 [相簿效能基線](ALBUM_VIEWER_DESIGN.md#檔案與效能基線)：內容分批、可見範圍虛擬化、固定縮圖網格及非同步縮圖快取；保留 200 張分組與原始閱讀順序。
- 內容區標頭的「右側版面配置…」打開版面配置視窗的「右側」並選好這個資料夾，從預覽區的「編輯右側版面」編輯它實際套用的版面（R-445；所有類型都有）；右側版面存在 `panelPresets`，書籍類型用哪一個由 `layoutRules.panel` 決定（R-409，見 [LAYOUT_RULES](LAYOUT_RULES.md)），與卡片版面獨立。封面是版面裡的圖片組件（R-362）：顯示資料夾封面，沒有時顯示第 1 張圖片，可移動、縮放或拿掉。沒選過版面時用內建的書籍右側：左側封面、右側放卡片上用到的欄位組件（沒有欄位時只有封面）。編輯器上方的方案工具列切換、新增、複製、改名、刪除右側版面，儲存時選中的成為書籍類型的版面。資料夾用哪個右側版面在版面配置視窗的「右側」設定（資料夾設定「外觀」只顯示目前的版面與來源）；資料夾列的選單「另做一份給這個資料夾…」複製這個資料夾目前用的版面、以資料夾名稱命名、指定給它，並打開編輯器（此時儲存不改類型的版面）。TOP 遵循 [右側內容](WORKSPACE_REVISION.md#右側內容與覆蓋層) 的條件式顯示，只回捲目前內容區。
- 閱讀器上方分成頁碼導覽、頁面模式（單頁、雙頁、首張獨立、閱讀方向）、縮放與沉浸閱讀；退出 ICON 在右上，圖片資訊在底部。
- 漫畫移除寬度／高度適應按鈕及 W／H 快捷鍵。圖片預設等比貼齊上方工具列與下方資訊列之間的實際可視高度，移除固定上下留白；縮放以貼合可視高度為 100% 起點／縮小下限，可繼續放大至 1000% 看細節（可調上限），不限制為原圖像素或可視區最大高度。放大後可拖曳平移，過寬頁面／雙頁可橫向拖曳，RTL 從右側開始。縮放用 Ctrl＋滾輪、`+`／`-` 與工具列，並保留重設；滾輪本身用來讀（見快捷鍵表，C-136）。相簿原有適應功能不受影響。

不額外縮小造成留白：預設與縮小下限都是貼合可視高度的 100%，可放大、平移與一鍵重設。
- 「沉浸閱讀」（F11，保留 T）進入作業系統全螢幕，即使應用原本為一般視窗也適用，並隱藏上方工具列、底部資訊與右上退出；再按 F11／T 或 ESC 退出沉浸後保留閱讀器，恢復原視窗狀態。滑鼠移到頂緣不叫出介面，以 F11／T 或 ESC 恢復。關閉閱讀器會釋放本閱讀器取得的全螢幕；閱讀設定／頁碼選單先關最上層。
- 頁碼、縮放按鈕與方向箭頭採 [共用閱讀器操作](UI_RULES.md#共用閱讀器操作)。鍵盤翻頁後閱讀區不顯示預設白色焦點框，工具按鈕保留鍵盤焦點提示。雙頁整組解碼後才原子換頁，等待保留舊頁；預載相鄰組、限制快取，快速操作只提交最後要求。圖庫背景 GIF 暫停。
- 閱讀方向按鈕的圖示與提示顯示目前「由右至左／由左至右」，按一下切換；沒有已存方向偏好時預設由右至左，既有明確偏好保留。
- 單頁與雙頁皆以整個閱讀區為基準只有一組點擊熱區，分左、中、右三等分：左右各三分之一翻頁，右至左時左側下一頁、右側上一頁，左至右時反向；中間三分之一顯示或隱藏工具列（沉浸閱讀時是展開或收起左側工具列與下方進度列，和小說閱讀器一致）；條漫模式不變。雙頁不在每張圖片各建立一組熱區，避免出現重複翻頁區或一次點擊翻兩次；拖曳平移／縮放操作不得誤觸翻頁。頁面完整顯示（未放大）時，按住左右拖動，頁面跟著指標橫向移動，每一頁（雙頁時是一組）各佔一整個閱讀區寬，像一條並排的畫面：相鄰的上一頁或下一頁就待在旁邊那一格的固定位置（用已預先載入的圖片，大小與顯示時相同），拖曳只是把整條畫面推過去，最多推一格；那一側沒有頁面時（第一頁往回、最後一頁往後）只有阻力。放開時超過閱讀區寬度約 15% 或快速甩動即翻頁，方向與按鍵相同（往左拖等於按 →），畫面停在放開的位置直到新頁準備好，新頁再從旁邊接續滑完，不先跳回原位；不夠門檻就連同旁邊的頁面一起彈回原位（約 150ms，關掉翻頁過渡或系統要求減少動態效果時，拖曳時頁面不跟手、旁邊的頁也不出現，放開時照同一個門檻判斷，夠了新頁直接出現、不夠就不動，和點擊與按鍵翻頁一致）；短距離仍當點擊，放大時拖動仍是平移，從左、右、下三個邊緣開始的拖動不翻頁（留給邊緣面板）。翻頁時新頁依閱讀方向滑入、舊頁同時往另一側滑出（約 200ms；往後翻時由左至右從右邊進來、由右至左從左邊進來），切單雙頁、載入或從佇列跳頁不滑動；系統要求減少動態效果時直接切換。使用者可以關掉翻頁過渡（工具列「翻頁過渡」或 A），新頁直接出現，適合一張一格、靠連續畫面表現的漫畫；這是閱讀習慣，記在這台電腦（`morph.readerTurnMotion`），所有書共用，不寫進資料夾記錄（R-378）。

## 漫畫檔案模式入口

漫畫專案不顯示中央「檔案」檢視入口，中央保留資料夾導覽、右側維持漫畫內容；舊偏好若留在檔案模式則回退資料夾模式，保留來源資料與閱讀能力。

一般媒體專案在大視窗切換到漫畫閱讀模式，仍保留底層媒體檔案瀏覽；不停用共用檔案列舉、刪除來源資料或改寫專案屬性。早期漫畫／相簿共用檔案總覽表示底層能力共用，不代表漫畫必須保留獨立的中央檔案入口。

## 閱讀視窗

- 視窗採程式內全畫面覆蓋層，退出鍵為 ESC（C-85），不以此承諾獨立原生視窗。
- 點哪張圖，就從該圖開始，而非固定回到第一張。
- 工具列位於上方，從左到右依序為：頁碼導覽（上一頁、頁碼選擇、總頁數、下一頁）、頁面模式（單頁、雙頁、條漫、首張獨立、閱讀方向、翻頁過渡；條漫時隱藏後三項）、縮放（縮小、百分比、放大、重設；條漫時換成寬度滑桿）與沉浸閱讀；沒有寬／高適應。除頁碼與縮放百分比外只用圖示，名稱與快捷鍵在提示中，使用中的模式以強調色標示。
- 沉浸閱讀時介面全部隱藏，三個邊緣各有一個滑出面板，滑鼠停在邊緣或以鍵盤聚焦其中時出現、離開即收起（滑鼠點過面板裡的按鈕不算聚焦，離開照樣收起）：左緣是純圖示的垂直工具列（與上方工具列同一份工具，不含頁碼導覽），下緣是進度條（上一頁、可拖動進度、下一頁、目前頁碼；由右至左時進度方向相反；滑鼠停在進度條上浮出該頁縮圖，拖動時只預覽、放開才跳頁），右緣是媒體檢視器的佇列。上緣不滑出任何東西；沉浸閱讀時外框的專案欄預覽不出現。沉浸閱讀時滑鼠停著不動約 2 秒就隱藏游標，一動就出現，停在左側工具列或進度條上不隱藏。
- 雙頁時頁碼選項顯示區間，例如 `1–2`、`20–21`；這些是格式例子，不表示已決定封面及奇偶頁配對規則。
- **條漫模式**（R-256）：頁面模式多第三種「條漫」（工具列 `[單頁｜雙頁｜條漫]`，快捷鍵 V 切換；D 只在單／雙頁間切換，條漫中按 D 回到原本的單／雙頁）。所有頁面上下連續、沒有間隙，用原生捲動；目前頁的前 2 頁到後 6 頁提前載入、一載入就在背景解碼，往下讀不會經過晚一步才出現的空白頁，捲動也不必等解碼，其餘頁面靠近時才載入（R-375）；寬度滑桿 10%～100%（縮放時畫面中央那一頁維持在畫面中央，R-414）（步進 5，Ctrl＋滾輪、`+`／`-` 也可調）取代縮放；隱藏上一頁／下一頁、首張獨立與閱讀方向。頁碼取畫面中央那一頁；方向鍵、空白鍵、Page Up／Down 捲一個畫面高（約九成），Home／End 到兩端，到底（最後一頁底部）顯示「已是最後一頁」提示與「前往下一本」按鈕，再按一次下一頁也會開啟下一本；進度條固定由左到右（往下＝下一頁），不跟單／雙頁的左右設定。前三頁有一頁高度超過寬度 2.5 倍時，提示一次「這本看起來是條漫［切換到條漫］［不用］」，不自動切換。模式、寬度與「已回答過提示」記在這本的閱讀紀錄（`reading.webtoon`、`webtoonWidth`、`webtoonAsked`）；沒記過寬度的書沿用這台電腦上次的寬度。

## 快捷鍵與工具行為

單頁起始、手動方向／首張獨立、Tooltip 與 F11／T 沉浸閱讀；沒有寬／高適應的手動切換。數值與復原時機是可調基線。

| 功能 | 鍵位 | 行為 |
| --- | --- | --- |
| 上一頁 | RTL：→；LTR：← | 單頁前一張；雙頁前一組。第一組停用，不循環；提示及按鈕動作跟隨方向。 |
| 下一頁 | RTL：←；LTR：→ | 單頁後一張；雙頁後一組。最後一組停用，不循環；提示及按鈕動作跟隨方向。 |
| 往下讀／往回 | 空白鍵、Page Down、↓／Shift＋空白鍵、Page Up、↑ | 頁面比閱讀區高（放大或相簿的寬度適應）時先捲約九成閱讀區高，到底（或到頂）再翻到下一頁（上一頁）；不受閱讀方向影響。翻到的新頁從頂端開始。條漫的同一組按鍵見條漫模式。（R-372） |
| 滾輪 | 滾輪／Ctrl＋滾輪 | 滾輪移動比閱讀區大的頁面，已經到底（頂）再滾才翻頁；翻頁與上一次翻頁或移動至少隔 0.25 秒，所以一路滾到底不會連翻。滾到最後一頁之後只提示「已是最後一頁」，不會用滾輪開下一本。Ctrl＋滾輪以游標位置為中心縮放。相簿的圖片檢視相同。（R-373） |
| 單／雙頁 | D | 手動切換，預設單頁；切換時保留目前圖片的定位。雙頁規則見下節。 |
| 翻頁過渡 | A | 開／關翻頁時的滑動；關閉時新頁直接出現。條漫模式無此項。（R-378） |
| 頁碼選擇 | G | 聚焦可搜尋的頁碼選擇器，單頁顯示頁碼，雙頁顯示區間，Enter 跳轉。大量選項避免全部同時渲染。 |
| 續讀與下一本 | — | 從第一頁開啟漫畫時，若資料夾記錄的閱讀頁碼（`reading.page`）不算讀完，就從該頁繼續並短暫提示「從第 N 頁繼續 [從頭開始]」；點其他頁開啟則照點的那頁，並短暫提示「上次讀到第 N 頁 [跳到第 N 頁]」（R-322）。以「退出」離開時保存；直接關閉檢視器或切換資料夾時，只有漫畫在開啟後換過頁或改過設定才保存，只是瀏覽不寫入。最後一頁再往後翻先提示「已是最後一頁」，從瀏覽區開啟且清單中還有下一個資料夾時一併顯示「下一本：名稱」，再按一次就在右側面板顯示下一本並從第一張圖片開始閱讀，沉浸閱讀中換本時保持沉浸（下一本沒有可讀圖片就退出全螢幕）。換本沒有固定時限：要求留著，直到下一本的面板收下它（圖片列出就開始閱讀），切換被拒絕或使用者改去別處才作廢。下一本還沒有自己的閱讀設定時，沿用上一本的閱讀方向、單雙頁、首張獨立、適應方式與條漫（不含頁數）；這些設定只當作初始值，下一本被讀過（換頁或改設定）離開時才連同頁碼寫進它的記錄（R-430）；ESC 或「留在這裡」關閉提示。資料夾裡的 CBZ 讀到最後一頁，同樣依檔名順序接到下一個 CBZ（R-415），換卷時閱讀設定（含沉浸閱讀）沿用上一卷，閱讀器不會被關掉（R-430）。 |
| 沉浸閱讀 | F11／T | 進入／退出系統全螢幕；隱藏全部介面，移到頂緣維持隱藏，左／下／右緣滑出工具列、進度條與佇列。焦點在頁面上時 Tab 不動，不會把焦點帶進隱藏的工具列讓它一直顯示（R-376）；工具列用滑鼠移到邊緣叫出，或用快捷鍵。 |
| 返回／退出 | ESC | 先關選單，再退出沉浸，最後關閱讀器；每次只處理一層。 |

漫畫高度依實際閱讀區計算，工具列換行、視窗大小及全螢幕改變時更新；不以捲軸出現與否反覆修正尺寸。圖片比例不同時，不把雙頁各自硬拉成相同寬高。切換圖片建議回到新頁頂端，調整視窗則重算縮放但不更換頁碼。

工具按鍵以 Hover／鍵盤聚焦的 Tooltip 顯示快捷提示（C-76、C-85），例如「沉浸閱讀　F11／T」；按鈕標示目前模式。輸入欄位、頁碼搜尋或選單操作中不攔截打字及游標鍵。

## 單／雙頁方向與配對

- **手動切換、預設單頁**，降低視窗變寬就意外換頁或改配對的情況。
- 提供由左至右／由右至左設定，無已存偏好時預設由右至左；顯示語意及點擊熱區依上述規則。
- 圖片模式（非漫畫，R-406）固定由左向右：不讀也不寫資料夾存的漫畫方向，沒有方向按鈕；翻頁固定沒有過渡（不顯示「翻頁過渡」按鈕與 A 快捷鍵，已存的設定不變）。
- 首張獨立是手動開關，不自動推定首圖是封面；其他特殊配對不由分類猜測。
- 建議將選項改名為「首張獨立顯示」，預設關閉，只在雙頁模式生效。開啟時為 `1`、`2–3`、`4–5`；關閉時為 `1–2`、`3–4`、`5–6`，不自動推定第一張是封面。
- 放在單／雙頁按鈕的閱讀選項 Popup，讓使用者看到配對結果，與 Tooltip 分開；C-85 已採每筆閱讀偏好獨立保存，具體可攜 schema 待設計，不變更分類或原圖。
- 頁碼區間依檔案順序表示；方向改變圖片左右擺放與各方向翻頁意義，不改原始頁序或配對。
- 尾端剩一張時單獨置中；不把它放大填滿兩頁，不把封面或缺頁誤當成空白圖片。
- 一個圖片檔本身已是跨頁（寬大於高）時，雙頁模式自動讓它單獨顯示，它前面落單的那一頁也單獨顯示，之後的頁面從它後面重新配對（R-374、C-136）。只看已載入頁面的尺寸：還沒載入的頁先照一般規則配對，載入後發現是寬圖才重排，所以直接跳到很後面時，中間沒看過的寬圖不影響配對。

## GIF 原則與效能

大量動圖會持續涉及圖片解碼與繪製。圖片尺寸、幀數、播放數量及設備都會影響成本，不能只按檔案數承諾順暢；以下是工程判斷，目前未執行本專案 GIF 效能測試。

| 選項 | 體驗與取捨 |
| --- | --- |
| **可見範圍播放，視窗外停止（已選）** | 可見範圍內的 GIF 播放，離開後停止。使用者未採用固定播放數上限；先前的 4 張只是原型建議，不得直接套成產品限制。 |
| 靜態縮圖，Hover／點按才播放（未選） | 保留作省資源模式候選，不替代目前已選的可見範圍播放行為。 |

已確認原則與建議實作細則：

1. 可見區播放、離開停止已確認。技術上建議替換靜態預覽／卸載動畫來源並保留占位；附近可預載縮圖，但不可因此在可見範圍外播放。圖片很多時再配合可視範圍渲染，不限制可瀏覽的總數。
2. 不能把「lazy loading」當成已載入 GIF 的暫停功能，也不以 CSS 隱藏保證停止解碼。一般圖片介面沒有影片式播放控制，需要管理實際動畫來源。
3. 開閱讀器時停止背景圖庫動畫已確認；遮罩覆蓋不一定改變幾何可見範圍，不能只靠可見區判斷。閱讀器只讓目前一頁或兩頁 GIF 播放。
4. 相鄰頁有限預載：翻到新頁後預先解碼閱讀方向的後兩組與前一組（GIF 除外），不預先解碼或播放整本漫畫。回到內容頁再依可見範圍恢復播放，不保證續播同一幀。
5. 建議上方資訊封面先用靜態預覽，避免同一張 GIF 在封面及圖庫同時播放；此為建議，不變更使用者要求的下方 GIF 支援。
6. 靜態縮圖放可重建本機快取，控制大小及上限。原始漫畫圖片留在原資料夾，不為這個功能全部再複製進 `.media-viewer/assets/`。

資料依據：

- [MDN Intersection Observer](https://developer.mozilla.org/en-US/docs/Web/API/Intersection_Observer_API)：可非同步觀察元素與視窗的交集，作為載入／動畫排程的依據。
- [MDN 圖片載入](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/img)：lazy 延後載入，預留尺寸可減少版面跳動；不能推論它會暫停已載入的 GIF。
- [MDN HTMLImageElement](https://developer.mozilla.org/en-US/docs/Web/API/HTMLImageElement)：圖片載入／解碼介面；動畫來源管理仍需另外設計。
- [web.dev：GIF 改影片](https://web.dev/articles/replace-gifs-with-videos)：影片格式可減少動畫資產的檔案量，可作為快取方案的參考；本機專案不能直接套用網頁流量數字當成渲染效能結論。轉碼會增加處理流程，首版建議先做可見範圍與播放數管理；若後續採用，只產生快取，不覆寫原圖。

## 分工與契約

- CARD 模板決定一筆資料夾卡片；內容資訊模板決定圖 1 上半部。C-76 已確認共用 CELL 編輯能力，但版面分開保存，避免修改其中一處就影響另一處。
- C-85 已採每專案分開保存 CARD 與各內容模板並可攜，每筆閱讀偏好獨立；仍引用穩定欄位身分，不改回舊的全部 project-scoped 值模型。
- 漫畫原圖從已選受管資料夾讀取，renderer 使用受控媒體介面；不把任意絕對路徑當成公開讀檔入口，也不假設目前只讀自訂 assets 的 API 已涵蓋漫畫檔案。
- 作品內容用目前資料夾直接圖片、檔名自然排序（如 1、2、10），封面／閱讀共用清單（C-85）。中央 [檔案檢視](MEDIA_WORKSPACE.md#檔案總覽) 與圖片／相簿統一，可彙總子資料夾並保留作品歸屬；不把跨作品彙總清單直接串入同一本閱讀。壓縮檔及 PDF 的既有能力見 [文件檢視器](DOCUMENT_VIEWER_DESIGN.md)。
- 閱讀器保留程式內覆蓋層，另提供系統全螢幕沉浸模式；退出後保留原選取及圖庫捲動位置。
- ESC 建議由最上層先處理：頁碼選單／彈窗 → 沉浸全螢幕 → 閱讀器 → 工作區放大。一次 ESC 不同時退出閱讀與取消 C-74 工作區放大。

## 驗證

1. 自然排序在同名／特殊字元、缺檔、相同排序值的穩定結果，以及圖片解碼範圍。
2. GIF 返回時的可調排程與資源釋放、省資源模式需先量測；沒有固定 4 張上限。
3. 手動閱讀方向、首張開關與配對還原案例；初始方向可由原型設定可調基線，不再重問已採單頁及現行縮放行為。
4. 閱讀器、選單、輸入與工作區放大的 ESC／焦點驗收，工具列及頁碼選擇的實際互動。
5. 每專案媒體模板與每筆閱讀偏好的版本格式；資訊區／圖庫捲動與 TOP 先回本內容區頂部作可調基線。

驗證涵蓋空資料夾、損壞圖片、大量高解析圖片／GIF、連續翻頁及切換資料夾時的資源釋放；只用受控測試資料，不讀取使用者的真實漫畫。
