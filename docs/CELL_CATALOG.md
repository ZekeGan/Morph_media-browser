# CELL 目錄

> 最後確認：2026-11-25（R-498 R-499）。卡片組件與欄位型別的現行契約；共用編輯行為見 [EDITOR_DESIGN](EDITOR_DESIGN.md)。值、版面與受控動作分開；取捨見 [決策索引](DECISIONS.md)。

## 現行契約

[CellKind](../shared/model.ts) 與 runtime 驗證是程式真相，新增種類需同步 renderer／驗證／可攜相容性。

| kind | 用途 |
| --- | --- |
| game-launch | 遊戲專案專用的操作按鈕：可用 `actionId` 指定任一遊戲操作（R-409：啟動、開資料夾、網頁或說明書；備用動作仍只限可啟動的動作），未指定時用預設啟動動作，再退回第一個可啟動的動作；使用資料夾已綁定的目標；未綁定時停用並提示，啟動前依現有規則確認；與遊戲頁的按鈕共用同一個 `runTarget` 驗證，不擴大其他組件的動作權限 |
| name／path | 目前資料夾系統名稱／路徑，不把舊設備路徑當可攜原值 |
| field-text | 依 attributeId 顯示文字 |
| field-tags | 多值標籤 |
| field-number | 數字 |
| field-date | 日期時間 |
| field-boolean／field-enum／field-url／field-date-only | 是／否、單選、網址、純日期 |
| static-text／spacer／system-info | 固定文字、占位間距、系統資訊 |
| image | 選用的獨立圖片組件；每個位置可各自選圖，空白不強制填寫 |
| divider | 分隔線，沿用組件尺寸／文字色 |
| open-folder | 經 main 驗證後開啟目前資料夾 |

缺 key 可顯示預設，但不寫回資料夾、不成為搜尋真值；搬入專案的欄位身分不可只按相同 alias 合併。

遊戲的 EXE／資料夾按鈕已有專屬工具列與獨立目標／參數，見 [遊戲](GAME_VIEWER_DESIGN.md)；不因此擴大所有 CARD CELL 的動作權限。

## 新增組件與型別

以下三種基礎組件與四種欄位型別已接入 CellKind、編輯器、資料欄位、搜尋／排序與可攜保存；schemaVersion 為 1。

| 基礎組件 | 目標行為 |
| --- | --- |
| 固定文字 | 文字保存在版面，用於標題／說明；不建立資料欄位或複製到各資料夾 |
| 空白間距 | 可調寬高並實際占用格線，抵抗自動向上排列；編輯時顯示虛線，瀏覽時透明 |
| 系統資訊 | 提供分類、檔案數、容量、遊玩時間、最後遊玩（R-308，從 M:orph 啟動的遊戲，讀本機紀錄；沒玩過顯示「尚未遊玩」）等系統／衍生資訊，使用既有索引或快取；未取得或未計算需明示，不為渲染卡片逐筆同步掃描 |

| 欄位型別 | 目標行為 |
| --- | --- |
| 是／否 | 支援未填、是、否；未知不能當作 false |
| 單選 | 用於狀態等受控選項，選項可管理，避免自由輸入造成名稱不一致 |
| 網址 | 驗證網址，可顯示自訂文字並透過受控入口開啟連結，不擴大為任意系統命令 |
| 日期 | 與日期時間分開，用於發售日／購入日等，不強迫補時間或時區 |

新增型別一併支援 CELL 顯示、資料夾設定編輯、搜尋／排序、值驗證、可攜保存及舊資料相容，不只增加選單。空值不寫假資料；型別儲存與查詢契約由 shared/fields.ts 與驗證持有，未因此授權批次遷移實際收藏。

評分先作為數字欄位的顯示方式，多行長文字先作為文字組件的呈現設定；不另新增獨立資料型別。操作區與方案管理見 [編輯器](EDITOR_DESIGN.md#組件與方案管理)。

## 遊戲封面與圖片填滿

### 遊戲封面

`game-cover` 組件已取消（R-437）：遊戲封面就是圖片組件設成「資料夾封面」，組件區不再有獨立的「遊戲封面」。圖片類組件可選「填滿容器（裁切）」或「完整顯示（保留空白）」（imageFit），縮放後圖片貼合容器。此項不改變既有遊戲邊界與封面匯入規則，見 [遊戲內容](GAME_VIEWER_DESIGN.md#遊戲內容頁)。

圖片填滿方式有三種：填滿裁切（`cover`）、完整顯示留白（`contain`）、完整顯示並以自身模糊放大圖填滿空白（`blur`）。封面常為長圖或寬圖，裁切會切掉標題字，圖片組件未設定時預設為 `contain`；舊版 `game-cover` 轉成的圖片組件保留原本的預設，沒有明確選過時寫成 `blur`。

### 其他規則

沒有群組（group）組件。載入舊專案時自動略過群組及其子組件（`withoutGroupCells`），下次保存才寫回。

不支援富文字、更多衍生值（如時長）、更完整的數值格式與單位、日期精度／時區；要加入需另立需求。來源日期不能與系統／購買時間混用；只有年／年月的資料不能硬補日期。

候選的來源、renderer、格式／空值／樣式及操作需各自明確；衍生值標示計算狀態／更新時間，不阻塞基本列表。其他外部應用不得變成任意系統命令輸入。更完整例子見 [封存目錄](history/agent-docs-before-cleanup.md#cell-catalog)，不是本輪必做清單。

系統檔案數與容量採已開啟內容的直接檔案快取，顯示最後計算時間；未知顯示「尚未計算」，不在卡片渲染時掃描。網址只允許 HTTP(S)，拒絕內嵌帳密與系統命令；單選定義 1～100 個唯一非空選項，已不在選項內的舊值仍可讀取，寫入新值時驗證。純日期檢查真實曆日，是／否以 null 表未填並保留 false；未知舊型別原樣保留。入口 shared/fields.ts、src/browse/folderStats.ts、tests/decided.test.ts。

## 編輯器操作

- 欄位只改顯示名稱可重新命名：欄位清單的鉛筆圖示，或組件設定「綁定欄位」旁的鉛筆；同名（不分大小寫）即時拒絕。型別建立後不能改，要換型別需刪除欄位重建。
- 單選選項：在管理欄位編輯，正在被資料夾使用的選項不能移除；組件條件的比較值改為選項下拉。選項不提供改名與排序（改名需批次寫入資料夾記錄，未核定）。
- 組件設定分為「內容／樣式」兩分頁（見 [EDITOR_DESIGN](EDITOR_DESIGN.md#資料與畫布)）；顯示條件在內容分頁的「沒有值時隱藏」與「其他選項」，有其他條件時自動展開。位置輸入限制 X＋寬 ≤ 12。
- 名稱：「版面文字」只存在版面，「文字欄位」綁定資料；組件按鈕與設定標題皆有一行用途說明。

## 文字、數字與條件的呈現設定

- **長文字**：名稱、路徑、文字欄位組件可勾「長文字換行顯示」（`wrap`）；預設維持單行、過長以「…」截斷。不改原值。
- **字級與對齊**：所有組件的 `style` 可選字級小／中／大（`fontSize`，各組件基準大小的 0.85／1／1.4 倍）與靠左／置中／靠右（`align`）；缺省為中與靠左。粗細、邊框、內距延後。
- **數字**：組件可設小數位數 `decimals`（0 到 6，缺省依原值）；一般文字呈現可設單位文字 `unit`（≤20 字）與位置 `unitPosition`（前／後，缺省後）。評分與進度只套用小數位數，不顯示單位。皆不改欄位原值。
- **顯示條件**：除有值／未填／等於／不等於外，數字、日期、日期時間欄位可用大於（`gt`）與小於（`lt`）；比較值須符合欄位型別，型別不符或未填一律不顯示。仍只能設一個條件。
- **多個條件與相對日期、依條件顯示文字**（R-239）：顯示條件最多 5 個，可選「全部符合／任一符合」；日期與日期時間可比「距今 N 天內／超過 N 天」。版面文字可設「依條件顯示文字」規則（最多 10 條），第一個符合的規則顯示它的文字，都不符合時顯示「其他情況」的文字，留空就不顯示。格式見 [DATA_FORMAT](DATA_FORMAT.md)。
- 以上皆為組件可選欄位，`schemaVersion` 維持 1；舊專案不需遷移。

## 備用欄位

- **已由欄位群組取代（R-226）**：編輯器不再提供備用欄位清單，新設定改用 [欄位群組](EDITOR_DESIGN.md#欄位群組)；既有組件的 `fallbackIds` 照下列規則讀取與顯示，內容分頁顯示舊鏈並可「轉成群組」。群組的取值、文字與標籤互通及「有值」判斷與下列相同。
- 欄位組件（`field-*`）依主要欄位及最多 5 個備用欄位的順序取值；第一個有值的欄位就是顯示（與複製）的欄位，兩者都有值時以排在前面的為準。空字串、只有空白、空清單及只含空白的標籤清單算沒有值；數字 0、布林 false 是有值。全部都沒有值時回到主要欄位（維持原本的未填與型別不符提示）。
- 同型別可備用；文字與標籤另可互通：文字組件將標籤以逗號加空格連接，標籤組件將整段文字當成一個標籤，不按標點拆分。可切換文字／標籤呈現，原始欄位型別與值不變；對應表格欄位及複製沿用相同內容。其他型別不轉換。
- 用途：不同來源網站的同義欄位（Steam 遊戲名、DLsite 作品名…）不複製資料，由組件決定顯示哪一個；不需遷移已匯入資料。有備用欄位的組件在 TABLE 另有一欄「<欄位名>（含備用）」，顯示並排序依序第一個有值的欄位；篩選仍只看單一欄位。
- 驗證：備用欄位須存在、型別相容、不重複、不含主要欄位。刪除欄位時：被刪的是主要欄位則改以下一個備用欄位為主，是備用欄位則從清單移除。

- **啟動遊戲組件的備用動作**：組件設定「備用動作」可列最多 5 個啟動動作；每個遊戲依序取第一個已綁定目標（種類相符）的動作，按鈕顯示實際使用的動作名稱；都沒綁定時顯示主要動作的「尚未綁定」。因此同一個組件可同時涵蓋 EXE 與捷徑的遊戲。尚未提供「逐個遊戲手動指定顯示哪個按鈕」，待使用者確認需求。

- **內容多時可捲動**：文字欄位、標籤、版面文字組件可勾選「內容多時可捲動」，保持格子高度並以滑鼠滾輪或鍵盤捲動查看；開啟時一律換行顯示。未勾選時維持原本的截斷。

- **內容過高時自動加高**（R-398，`growMax`，暫定）：文字欄位、標籤、版面文字、名稱、路徑組件可勾選，內容放不下時多佔列（最多加 1～20 列，預設 3），同欄位範圍下方的組件跟著下移；與「內容多時可捲動」擇一，開啟時一律換行顯示，超過上限的內容照舊被截掉。編輯器畫布不自動加高、也不標示截掉，只有卡片實際長高。量測用 ResizeObserver、同一張卡片批次更新，第一次量測在繪製前完成。
- **隱藏的組件不佔高度**（R-398）：條件不符或「沒有值時隱藏」的組件不輸出格子；某一列只剩被隱藏的組件（沒有任何可見組件覆蓋）時整列收起，下面往上補。原本就沒有組件的空列視為刻意留白，照舊保留。計算在 `shared/cardGrid.ts` 的 `placeCells`。編輯器畫布一律顯示全部組件。
- **遊戲元件**（R-409）：編輯器元件區的「遊戲」分類放啟動遊戲、遊戲附加按鈕、遊玩時間、最後遊玩、遊戲引擎（系統資訊 `engine`：掃描偵測到的引擎，沒有時「未偵測到」）與開啟資料夾。**遊戲附加按鈕** `game-extra`（暫定，`gameExtra`：`save` 開啟存檔資料夾、`steam` 用 Steam 啟動、`store` 在商店開啟）：可用性只問畫面上看得到的卡片（`IntersectionObserver`），同時進入畫面的一次批次詢問（`gameAvailability`，一次最多 60 筆），結果依資料夾記錄版本記在記憶體，按重新整理（同時重新掃描）時清掉；回覆前按鈕淡色不可按，不能用時灰色並在提示與無障礙名稱說明原因（沒有 Steam App ID、這台電腦沒有安裝 Steam、沒有商店網址、還沒有存檔、找不到存檔資料夾、不是遊戲資料夾）。詢問只讀資料夾記錄與 `steam_appid.txt`、依掃描時的引擎推算存檔位置，不偵測引擎、不建立或寫入記錄。
- **內建右側**（R-409、R-469，**暫定**）：依封面形狀排，全用一般組件：音樂是左邊方形封面（寬 5、高 4，圖片組件設為資料夾封面），右邊專輯名稱、演出者·年份、曲數·總長度（R-438 的系統資訊小組件）；書籍與影片是左邊直式封面（寬 4、高 6），右邊名稱加該類型的組件（影片：影片數、`video-play`；書籍：卡片欄位，單本 EPUB 另在名稱下加書名、作者；「繼續閱讀」在書籍頁自己的操作列，內建版面不重複放）；遊戲是上方橫式封面（寬 12、高 6，`blur`），名稱在下，遊戲頁不再有寫死的橫幅；一般是空的。舊的 `album-facts`、`video-facts`、`book-card` 在專案升到 v4 時換成同位置的小組件（[DATA_FORMAT](DATA_FORMAT.md#已有的升級步驟)）；更早的 `game-cover`、`album-info`、`video-info` 在 v3 換掉。
- **專輯、影片、書籍的小組件**（R-438，暫定，前段：右側用）：比照遊戲的系統資訊組件，系統資訊新增 `albumName`（專輯名稱，沒有標籤用資料夾名）、`albumArtist`、`albumYear`（播客不顯示）、`trackCount`（播客顯示集數）、`totalLength`（讀完每首長度才顯示）、`videoCount`、`bookTitle`、`bookAuthor`（只有一本 EPUB 時）、`pages`、`readPage`（漫畫：最近讀的卷，否則資料夾圖片）；`readProgress` 沿用。另有按鈕組件 `video-play`（播放影片／繼續觀看）與 `book-continue`（繼續閱讀／開始閱讀，開啟的對象與頁面下方的按鈕相同）。它們只讀目前資料夾的右側頁面已讀到的內容，在卡片與編輯器預覽中先顯示「—」或按鈕名稱；卡片上的專輯名稱、演出者、年份、曲數、總長度、影片數（後段，R-438）：卡片進入畫面時，視窗把這些資料夾（一次最多 60 個）批次問 main（`folderFacts`，`electron/media-facts.ts`）；main 數資料夾直接包含的音訊與影片檔（不含隱藏檔，與資料夾清單一致），讀前 3 首的標籤（專輯、演出者、年份，三首一致才採用），結果存在本機 SQLite 索引 `media-facts.sqlite`（可刪除重建，不寫資料夾記錄，也不建立或修改資料夾裡的任何檔案）；資料夾修改時間、媒體檔數量或總大小改變時重新讀取（總大小在修改時間與數量不變時最多每分鐘重算一次）；索引損壞時移到一旁重建，程式結束時關閉。總長度在背景逐首讀檔頭加總（最多 300 首，一首讀不到就不顯示部分和），讀完前顯示「—」，視窗隔幾秒再問，最多約一分鐘，卡片回到畫面時再問。總長度有自己的排隊（R-455），標籤不必等別的資料夾讀完長度；最後被問的資料夾先讀，最多 40 個等候，較早的丟掉，等卡片再出現時重新排入。只讀可讀取的資料夾，遊戲 ROOT 內部不讀。編輯器的「專輯」「影片」「書籍」分區列出它們，舊的 `album-facts`／`video-facts`／`book-card` 仍可用。
- **資料夾封面**（R-409，暫定）：圖片組件「沒有手動選圖時」可設為「資料夾封面」，新加的圖片組件預設用它：資料夾指定的封面 > 記錄裡第一張非來源附加（截圖、橫幅、標誌、圖示）的圖片 >（資料夾有音訊時）第一首的內嵌封面 > 唯一一張檔名像封面的圖片（`cover`、`folder`、`front`、`artist`，所有類型）> 資料夾內第一張圖片（R-437）。前兩步由 renderer 直接用記錄資產，其餘由 main 的 `media://cover/<rowId>` 統一判斷（`electron/explorer-content.ts` 的 `folderCover`）；卡片、遊戲頁封面、右側封面與書籍模板封面共用這條規則（`src/cells/folderCover.ts`）；卡片用縮圖，右側面板用原圖（R-499）。換封面一律在資料夾設定的「圖片」頁，所有類型都有「封面」區。
- **沒有手動選圖時**只有三種：資料夾封面、第 N 張圖片、留空（R-511）。舊版存的「來源匯入的橫幅／標誌／圖示」（`imageRole`）照資料夾封面顯示，編輯器也顯示成「資料夾封面」，改選其他項目時移除。從網站匯入的圖片仍可在資料夾設定的「圖片」頁手動選用。
- **圖片組件依位置選圖**：圖片組件「沒有手動選圖時」也可設為「顯示資料夾內第 N 張圖片」（1～999）。依檔名自然排序，只看該資料夾直接包含的圖片（不含子資料夾、隱藏檔）；優先順序是資料夾手動選的圖 > 第 N 張 > 留空；該資料夾沒有第 N 張時顯示「沒有圖片」。卡片上以縮圖呈現（最長邊 640px，只縮小不放大，R-498），右側面板顯示原圖（`?full=1`，R-499）；不複製或改寫原檔。

- **標籤超出時**：不可捲動的標籤組件顯示塞得下的標籤，後面接「+N」，完整清單在提示文字；可捲動的組件不隱藏任何標籤。
- **搜尋與備用欄位**：以某欄位搜尋時，也會搜尋任何組件列在它之後的備用欄位（只擴大查詢的欄位集合，不增加索引內容；群組見 [欄位群組](EDITOR_DESIGN.md#欄位群組)）；範圍是「任一欄位含關鍵字」，不是「只看顯示中的那一個」。表格欄位的排序仍是單一欄位，不套用備用欄位。

- **欄位清單顯示預覽資料**：編輯器左側欄位清單的每個欄位，在欄位名稱下以一行顯示「使用真實資料預覽」所選資料夾目前的值（過長以「…」截斷，滑過顯示完整內容；沒有值顯示「（此筆沒有值）」），不必放進組件才知道內容。

## 組件樣式

- `style` 的選用欄位（缺省就是原樣）：`fontSize`（特小／小／中／大／特大 = 0.72／0.85／1／1.4／1.8 倍）、`weight`（細／一般／粗）、`italic`／`underline`／`strike`、`align`／`valign`、`lineHeight`（緊／鬆）、`letterSpacing`（加寬）、`padding`（緊湊／寬鬆）、`radius`（小／大）、`borderColor`＋`borderWidth`（細／粗，兩者並存才顯示）、`opacity`（柔和 0.7／淡 0.45）。不提供字型家族、陰影、漸層與自由 CSS，以維持三主題一致。
- 標籤組件：`tagColors: 'namespace'` 依分類上色（female、male、language、parody、character、artist、group、cosplayer、mixed、other、reclass，其餘灰色）；`tagPrefix: false` 隱藏分類前綴。單選欄位：`optionColors`（選項→十六進位色）供「狀態徽章」使用；移除選項時一併移除其顏色。
- 編輯器「樣式」分頁（R-233）：上方「套用預設樣式」選單（內建：標題、次要說明、強調；此專案的樣式），旁邊「⋯」有存成樣式…、刪除樣式、清除樣式（保留顏色）。下面分兩段可收合：**文字**（預設展開：字級、粗細與斜體／底線／刪除線、水平與垂直對齊、文字顏色、行距與字距，以及換行、捲動等組件專屬選項）與 **外框**（預設收合，收合時標題列寫出已調整的項目：背景顏色——「無」即透明——、邊框與邊框顏色、圓角、內距、透明度）。和預設不同的段落標小點，可「重設」該段（文字段保留顏色；外框段把背景改回透明）。標籤顏色與分類前綴在內容分頁的顯示方式下面。位置與大小在最下方「進階」。

## 欄位呈現與互動

沿用既有欄位型別：enum／boolean 可選狀態徽章，number 可顯示評分或進度並設定滿分／總量；只截斷呈現，不改原值。欄位可啟用複製，0 與 false 保留；透過受信任主程序複製目前欄位，不開放一般網頁剪貼簿權限。

組件可依另一已綁欄位的有值／未填／等於／不等於決定內容顯示，保留格位以免版面跳動；編輯預覽仍可選取。條件欄位刪除時引用組件亦納入影響確認。公式與腳本延後（見 [OPEN_DECISIONS](OPEN_DECISIONS.md)）。CELL 群組不存在，舊專案的群組設定載入時略過。
