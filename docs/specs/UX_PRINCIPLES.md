# 產品體驗與互動前置定義

> 最後確認：2026-11-28（R-556）。本頁不綁定特定介面版型，而是從 M:orph 現有核心能力出發，定義產品邊界、心智模型、漸進式揭露與互動文法，作為後續介面設計、減法與優化的共同基準。

## 1. 產品定位與非目標

- **定位**：一套以本機資料夾為基礎、**不動原檔**的個人收藏瀏覽、整理與消費工具（涵蓋圖片、漫畫、小說、文件、影音與遊戲）。
- **核心價值**：在不更動既有硬碟目錄結構的前提下，讓本機資料夾立刻具備視覺化瀏覽、跨類型閱讀／播放／啟動，以及可隨資料夾帶走的整理資訊。
- **非目標（Non-Goals）**：
  - **不是檔案總管替代品**：不為瀏覽而搬移、改名、壓縮或刪除使用者的原始檔案。
  - **不是雲端服務或自動爬蟲**：不主動背景連網、不強制帳號同步、不做未經確認的批次網路抓取。
  - **不是單一媒體專用工具**：核心在於多類型收藏共存；內建檢視與播放以「順手、免切軟體」為目標，遇特殊格式可無縫交給外部程式。

## 2. 資料歸屬與信任契約

任何介面設計都應清楚傳達並遵守以下承諾：

1. **原始檔案不可侵犯**：瀏覽、移除專案、清除資訊、備份與還原，永遠不更動使用者的原始媒體與遊戲檔案。
2. **記錄跟著資料夾走（可攜優先）**：標籤、評分、封面、來源、閱讀進度等整理資訊屬於資料夾本身；本機索引可隨時重建，資料夾搬移或換機後重新連結即可復原。
3. **保護區絕不污染**：偵測到遊戲或獨立程式主目錄時，保護其內部不寫入任何記錄檔；這是「保護狀態」而非錯誤。
4. **大範圍或破壞性動作必先預覽**：清除記錄、還原備份、覆蓋設定前，必先展示受影響範圍並確認，且盡可能保留復原路徑。

## 3. 核心概念字典（心智模型收斂）

將系統概念分為「初期必懂」與「按需認識」兩層，避免新使用者初期承受過多專有名詞：

| 層級 | 概念 | 給使用者的白話定義 |
| --- | --- | --- |
| **一級（Day 1 必懂）** | **專案** | 指定要管理的某一個根資料夾（例如「我的漫畫庫」）。 |
| | **作品／資料夾** | 專案底下的收藏單位；系統會自動判斷類型（漫畫、遊戲、音樂、影片、一般）。 |
| | **資訊（記錄）** | 附掛在資料夾上的標題、封面、標籤、評分、啟動目標等；跟著資料夾走。 |
| **二級（按需認識）** | **專案群組／最愛** | 把多個專案分類與置頂的清單整理方式。 |
| | **欄位與欄位群組** | 自訂或從外部來源匯入的資料項目；多來源同義欄位可組成群組自動補位。 |
| | **版面與套用規則** | 決定資料夾呈現方式的外觀模板，可依預設、類型、層級或單一資料夾指定。 |
| | **共用 vs 私有資訊** | 只有當同一個資料夾同時出現在多個專案時，才需要區分的資料範圍。 |

> **設計約束**：二級概念在未被觸發前，不應佔用 Day 1 的主視覺焦點（例如未出現重疊專案時不顯示共用／私有切換；未建立多套版面時不強調複雜套用規則）。

## 4. 能力分層（Day 1 ／ Day 7 ／ Day 30）

依使用階段決定功能的顯眼程度與揭露時機：

- **Day 1（開箱即用，零設定就該成立）**
  - 連結資料夾建立專案（偵測到既有記錄時，優先引導接回）。
  - 自動判斷類型與封面，立刻以視覺化方式瀏覽。
  - 直接檢視與消費：翻圖／讀漫畫（含 ZIP／CBZ）／讀小說與 PDF／播影音（含外掛與內嵌字幕、跨專案播放佇列）／啟動遊戲。
  - 以關鍵字快速搜尋並跳轉到資料夾。
  - 切換語系與外觀主題。
- **Day 7（開始整理收藏）**
  - 補充資料夾資訊：手動填欄位、選／匯入封面、貼上網址預覽並選擇性匯入外部資料。
  - 修正自動判錯的資料夾類型、確認或排除疑似遊戲目錄。
  - 綁定遊戲啟動目標（EXE、參數、捷徑、外部連結）與記錄遊玩時間。
  - 切換多視角瀏覽（卡片、表格排序、結構樹、攤平檔案總覽）。
  - 管理多個專案（分組、最愛、排序）。
- **Day 30（重度客製與長期維護）**
  - 自訂呈現版面（積木排版、樣式與條件顯示）與多套版面規則。
  - 管理自訂欄位與跨來源欄位群組。
  - 使用進階搜尋語法（排除、任一、數值／日期區間）並儲存常用搜尋。
  - 設定外部執行工具（影片播放器、Locale Emulator、Flash Player）與網站金鑰。
  - 建立／匯出／選擇性還原備份、處理失聯或損壞記錄、清理受管資訊。

## 5. 五大核心任務流與體驗目標

不論介面形式如何演進，五條最高頻路徑應滿足以下目標：

1. **導入收藏**：選資料夾 → 確認名稱 → 立刻看到可瀏覽結果（3 步內完成），過程中明確傳達不動原檔。
2. **找東西與瀏覽**：在「看整體目錄」與「看單一作品內容」之間低成本切換，不迷失層級；隨時可跨專案以關鍵字直達目標。
3. **消費媒體與啟動遊戲**：從看到作品到開始閱讀／播放／啟動最多 1–2 次操作；進度自動保存；不支援格式可一步交由外部程式開啟。
4. **補充與修正資料**：系統主動提示缺漏項目（封面、啟動檔、作品資料），順著提示一步到位補齊；外部匯入資料預設保護手動修改不被覆蓋。
5. **微調外觀與長期搬遷**：微調目前外觀應能直達編輯，不必先理解複雜規則；資料夾搬家或換電腦時可無痛接回原有專案與記錄。

## 6. 全域互動文法與語意原則

- **漸進式互動深度**：輕量動作（瀏覽、預覽）不打斷脈絡；重量動作（沉浸閱讀、版面設計、深度設定）可進入專注視圖並一鍵退回原位。
- **一致的保存預期**：
  - 檢視偏好（排序、模式、欄寬、主題、閱讀進度）→ **即時自動保存**。
  - 結構與內容編輯（資料夾欄位、版面設計、專案設定）→ **明確的未保存狀態提示，離開前防呆確認**。
- **一致的語意色系與語氣**：
  - **中性／資訊色**：系統保護狀態（遊戲保護中）、待確認建議（疑似遊戲）、選填設定（網站金鑰）。
  - **警示／危險色**：只保留給真正的異常（失聯、記錄損壞）與不可逆動作（清除資訊、刪除備份）。
- **可預期且可逆**：刪除／清除／覆蓋前必先預覽摘要；能退回的操作（如還原設定）提供復原入口。

## 7. 設定歸屬原則

每個選項在設計前先依影響範圍決定歸屬層級，同類設定只放一處：

1. **應用程式層（跨全部專案）**：外觀主題、介面語系、外部執行程式、網站金鑰、來源偏好語系、全域備份與還原。
2. **專案層（整個根資料夾）**：專案名稱、連結狀態與移除、版面模板與套用規則、欄位與欄位群組定義、已儲存的搜尋。
3. **檢視層（當下怎麼看）**：瀏覽模式、排序方式、顯示深度與密度、檔案篩選範圍（按專案記憶，不寫入資料夾可攜記錄）。
4. **資料夾層（單一作品）**：作品欄位值、封面與圖片、類型判定、遊戲邊界與啟動目標、單一資料夾專屬版面覆寫。

## 8. 現實資料與邊界狀態承諾

任何新介面定案前，須同步驗證以下真實資料情境：

- **缺資料**：無封面、無自訂欄位、空資料夾、空檔案清單。
- **極端量級**：超長多語系檔名、深層巢狀目錄、單一資料夾上萬個檔案。
- **混合與異常**：同目錄混放漫畫與遊戲、外接硬碟離線失聯、壞檔或瀏覽器不支援編碼、被較新版本寫入的記錄。
- **視窗尺度**：寬螢幕與窄視窗（如 900px 以下）皆可完整操作且不遮擋退路。

## 9. 已對齊的核心場景互動規範

### 瀏覽區與詳情面板協作

1. **預設滿版瀏覽**：首次進入專案預設收起右側詳情面板，讓列表滿版呈現；單擊任一資料夾時自動滑出右側詳情面板預覽，之後記住使用者的展開／收合偏好。
2. **雙擊語意分流**：分類資料夾（有子資料夾）雙擊進入下層；純作品資料夾（無子資料夾或受保護遊戲）雙擊直接展開全寬詳情／閱讀檢視，不出現空白子資料夾列表。
3. **右鍵極簡選單**：對卡片或表格列按右鍵開啟極簡常用選單（資料夾設定、在檔案總管開啟、變更類型、指定版面）。
4. **單一視角切換**：收斂原「資料夾／檔案」與「逐層／所有作品」為單一軸線——`逐層瀏覽` ／ `所有作品` ／ `檔案總覽`。
5. **統一逐層退回**：`Esc`、滑鼠側鍵返回或面板關閉／返回鈕一律依序退回上一層（沉浸閱讀 → 全寬詳情 → 原列表並保留捲動與選取位置）；窄視窗時詳情面板以覆蓋層呈現。

### 資料夾設定與補資料流程

1. **匯入欄位點即編輯**：網站匯入的欄位直接點擊即可編輯（不需先按「改成手動」），修改後自動標記為手動值以防重抓覆蓋，並提供「恢復來源值」退路。
2. **遊戲操作緊湊化與就地新增**：資料夾設定「遊戲操作」分頁採單行緊湊清單（整合自動偵測按鈕與快速加入，未設定專案操作折疊、主啟動置頂），頂部即可新增專案共用操作；啟動參數改為類 Steam 單行輸入並支援獨立儲存與清除目標，與 Locale Emulator 一併收於各列展開區。遊戲頁操作列採主次分層（主啟動實心、輔助輕量帶圖示、未綁啟動檔原地引導、遊玩時間獨立成行）。
3. **保存預期分層與回饋**：表單欄位維持明確「保存／放棄」，單次選擇（類型、版面、封面）即時生效並補上輕量「已套用」回饋。
4. **缺漏引導精簡與前移**：「還可以補上」在資料夾設定頂部以精簡可收合形式呈現；詳情面板在缺少關鍵項目（如遊戲未綁啟動檔）時提供輕量一鍵補上入口。

### 首次建庫與空狀態引導

1. **極簡空首頁**：尚無任何專案時隱藏空的「未分類」區塊，保留單一「新增專案」主按鈕，搭配 3 步極簡流程圖示（不放額外安心承諾文案）。
2. **視覺分流與安靜掃描**：卡片以中性盾牌圖示標示遊戲保護；狀態列將「待確認」與橘紅色「問題」分色分流；首次掃描結束不彈出額外橫幅。
3. **零精靈進場**：首次啟動自動跟隨系統語系與預設主題，不加歡迎彈窗，維持既有設定入口。

### 版面配置與積木編輯器整合

1. **分裂式快捷入口**：工具列版面按鈕主按直達「編輯目前版面」，旁箭頭／選單開啟「版面配置」視窗與快速切換預設版面。
2. **規則視窗自動降噪**：「版面配置」視窗未設定「依層級」規則時預設收合該區塊；僅有一套版面時提供精簡提示，降低視覺雜訊。
3. **起手範本收納＋屬性兩頁分層**：起手卡片範本（大封面極簡、資訊完整、緊湊清單）收進版面下拉選單的「新增版面／套用範本」，不單獨佔用頂列按鈕；右側屬性檢查器收斂為「內容／樣式」兩頁，將「條件顯示」與座標／邊框細調折疊進「進階」。
4. **專注畫布與左欄精簡**：進入編輯器時自動暫時收起左側專案欄（離開時恢復）；頂列收斂為 4 組（返回、版面下拉、預覽資料夾切換、復原／重做與儲存）。左欄素材改為緊湊單行（說明移至 Tooltip），固定區塊（資料夾資訊 → 遊戲 → 排版）在上、動態成長的「你的欄位」置底。
5. **「你的欄位」工具列與清單降噪**：標題列僅放 `👁`（開啟變亮色膠囊 `有值 ×`，取代下方隱藏提示列）、`＋`（新增）與 `⋯`（收納管理全部欄位、加入常用欄位、全部展開／收合）；僅有單一來源（如自建）時省略來源折疊頭，單列 `⋯` 於 hover／焦點時浮現。

## 10. 主工作區視覺預算與空間配置（方案 2）

以 **80/20 分層原則**（不刪減重度功能，按使用頻率分配到一級常駐／二級收納／三級專頁）控管畫面密度：

- **三欄頂部齊平與右側全高**：左側專案欄、中央瀏覽區、右側詳情面板皆從標題列正下方全高貫穿。
- **主工具列單排合一（最多 5 組控制項）**：在專案根目錄將「返回／前進＋標題（筆數）」與主工具列合為單排（左：導覽；右：單一視角切換、三模式、排序、版面分裂鈕、檢視選項 Popover）；進入深層子資料夾或窄窗時才展開第二排極薄麵包屑條。每列卡片數、每頁筆數、層級深度與樹狀卡片開關統一收進檢視選項 Popover。
- **右側面板單排頂部（最多 4 個常駐互動點）**：標題列同一排放置「類型圖示＋標題」、「`[內容｜設定]` 膠囊切換」、「放大」、「`⋯` 與關閉」，省去獨立分頁列。低頻動作（在檔案總管開啟、詳情版面配置、有子資料夾時的進入此資料夾）收進 `⋯`；並排模式下隱藏重複的返回／前進，僅在全寬展開時顯示。內容頁「資料夾詳情」路徑採點即複製條，下方媒體工具列採 80/20 左右分組（左類型膠囊＋啟用時「含子資料夾 ×」；右排序、排列切換與收納範圍／分組的檢視選項 Popover，窄寬自動折為平衡兩段）。
- **資料夾設定頂部壓縮**：路徑收為單行省略（點即複製、hover 看全路徑）；「還缺」縮為單行可展開膠囊；「從網站匯入…」預設收合為頂部動作按鈕＋來源小徽章，點開才展開輸入／搜尋框。
- **全域搜尋（`Ctrl+K`）命令列化**：採單行輸入列（搜尋框＋`?` 語法速查＋範圍切換＋有輸入才亮的保存鈕）、有存過常用搜尋才顯示膠囊列（尚無時隱藏）；結果列表支援 `↑/↓` 選擇與單擊／`Enter` 直開，取消底部冗餘按鈕列改為極簡鍵盤提示列。
- **應用程式設定四頁分流**：拆為「外觀與語言」「外部工具」「網站金鑰」「備份與還原」四頁，並於金鑰與備份頁首補一句簡短說明（選填／僅備份設定與記錄不複製原檔）。
- **閱讀器與迷你播放器降噪**：閱讀器非沉浸頂列收斂為 5 組高頻控制（關閉、頁碼、單／雙頁／條漫、縮放、沉浸），低頻習慣（翻頁方向、首頁單頁、翻頁動畫、開啟資料夾）收進 `⚙` Popover；跨專案迷你播放器避開底部狀態列與分頁控制，展開佇列時 `Esc` 僅收起抽屜不中斷背景播放。
