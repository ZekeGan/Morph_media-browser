# 版面配置規則

最後確認：2026-11-17（R-413）

一個專案的卡片版面與右側版面，都由同一套規則決定，在同一個「版面配置」視窗設定。程式：[layoutRules.ts](../shared/layoutRules.ts)。

## 決定順序

每個資料夾依序找第一個成立的規則（卡片與右側各自一套，形狀相同）：

1. **資料夾專屬**：這個資料夾自己指定的版面。
2. **作品依類型**：資料夾算作品時（判斷同「所有作品」，見 [WORKSPACE_REVISION](WORKSPACE_REVISION.md)），用它類型（遊戲、書籍、音樂、影片、一般）的版面。作品裡的作品照樣用自己類型的版面，所以同一類型在任何深度都長一樣。
3. **一般資料夾依層級**：不是作品的資料夾，用它所在層級的版面；第 1 層是專案根目錄底下那一層。
4. **版面 0**：以上都沒有（含沒設定的層級、之後新建出的更深層、根目錄本身），用專案的預設版面。

規則指向的版面被刪除時跳過該條，從下一條繼續；刪除版面時同時從所有規則移除。

## 版面配置視窗

- 入口：瀏覽工具列原本的版面下拉選單改成按鈕，按鈕文字是目前資料夾套用的版面；旁邊的「編輯版面」按鈕不變（編輯版面內容）。
- **預設設定**：各類型的版面；第 1 層到目前最深一層的版面（更深的層用版面 0）。卡片與右側各一欄。
- **樹狀設定**：用與 TREE 檢視相同的 @xyflow/react＋Dagre 畫出資料夾結構，一般資料夾與作品是兩種節點，節點標出套用的版面與來源（資料夾專屬、類型、層級、版面 0）；點節點可指定或清除資料夾專屬版面。預設從目前資料夾展開兩到三層，其餘折疊，附搜尋；遊戲 ROOT 不往內展開。
- 專案設定與資料夾設定外觀頁不再各自存版面選擇，只顯示目前版面與來源，並連到這個視窗。

## 資料

專案記錄的版面規則欄位 layoutRules（暫定，接上畫面時加入）：`{ card?, panel? }`，各是 `{ types?, levels?, folders? }`：`types` 以資料夾類型為鍵、`levels[0]` 是第 1 層、`folders` 以資料夾 ID 為鍵，值都是版面 ID。舊欄位 `kindLayouts`（音樂與影片共用 `media`）、`folderLayouts`、`bookPresetId`、`folderBookPresets` 讀取時換算成同樣的規則，格式升級時移除，見 [DATA_FORMAT](DATA_FORMAT.md)。
