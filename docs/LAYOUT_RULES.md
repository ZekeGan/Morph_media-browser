# 版面配置規則

最後確認：2026-11-25（R-496 R-497）

一個專案的卡片版面與詳情版面，都由同一套規則決定，在同一個「版面配置」視窗設定。程式：[layoutRules.ts](../shared/layoutRules.ts)。

## 決定順序

每個資料夾依序找第一個成立的規則（卡片與右側各自一套，形狀相同）：

1. **資料夾專屬**：這個資料夾自己指定的版面。
2. **作品依類型**：資料夾算作品時（判斷同「所有作品」，見 [WORKSPACE_REVISION](WORKSPACE_REVISION.md)），用它類型（遊戲、書籍、音樂、影片、一般）的版面。作品裡的作品照樣用自己類型的版面，所以同一類型在任何深度都長一樣。
3. **依層級**（一般資料夾）：不是作品的資料夾，用它所在層級的版面；第 1 層是專案根目錄底下那一層。
4. **預設版面**：以上都沒有（含沒設定的層級、之後新建出的更深層、根目錄本身），用專案的預設版面。

**詳情版面**（R-409）的規則形狀相同，但依頁面的類型決定，不看資料夾算不算作品：資料夾專屬 → 該類型的版面 → 所在層級的版面 → 右側預設版面；都沒有時顯示該類型的內建詳情（書籍是左側封面加卡片欄位，其他類型不顯示）。編輯器保存時選中的詳情版面成為該類型的版面；為單一資料夾開啟時不改類型的版面。

規則指向的版面被刪除時跳過該條，從下一條繼續；刪除版面時同時從所有規則移除。

## 版面配置視窗

- 入口（R-445）：版面的指定與編輯都從這個視窗進入。瀏覽工具列的按鈕（文字是目前資料夾套用的版面）、內容區標題列的「詳情版面配置…」圖示（所有類型都有，開在「詳情」並選好該資料夾）、資料夾設定「類型與版面」的兩個按鈕都打開它；編輯版面內容一律按預覽區的「編輯卡片版面」或「編輯詳情版面」，打開的是所選資料夾實際套用的版面。右側「新增欄位」是加欄位的捷徑，照舊打開卡片編輯器。
- **左側規則**：依套用順序由上往下：作品依類型（只列專案裡有資料夾的類型；沒有的類型設定保留但不顯示）、一般資料夾依層級（只列有層級規則可套用的資料夾的層級，一層都沒有時整段不顯示），最底下是「預設」版面；清單工具列最左邊的按鈕可收合或展開整個規則欄，每一組規則也可按標題各自收合，都記在這台電腦（R-444）。預設版面下方寫它目前套到幾個資料夾；類型與層級規則寫「使用中 N／共 M 個」（M 是它可套用的資料夾數）（R-444）。沒設定的選單顯示「沿用預設（版面名稱）」，背景與文字比設定過的稍暗（滑過或取得焦點時恢復），設定過的選單左側有該來源的顏色線（R-489）。四種來源各有專用顏色（`--source-type／level／default／own`，三個主題各調一組：類型藍、層級琥珀、預設灰、專屬洋紅）：資料夾列左邊是 5px 色條，右邊是實心標籤，工具列的圖例就是同樣的標籤；色條對底色至少 3:1、標籤文字至少 4.5:1（R-490）。
- **資料夾清單**（視窗右半）：目前資料夾與底下的資料夾，用縮排表示層級，同一層依名稱排序（數字依大小，R-496），可展開、收合與搜尋；預設展開兩層。每列顯示套到的版面名稱與彩色來源標籤（類型、層級、預設、專屬，左側色條同色）；滑過、鍵盤移入或選取那一列時才顯示版面選單（R-444）。沒指定時選單顯示依規則套到的版面，選一個就成為此資料夾專屬，旁邊的 ✕ 清除；選到的正是規則本來給它的版面時不建立專屬（多選套用亦同）；層級規則能套用的資料夾在名稱後標「第 N 層」（R-444）；專屬的列名稱加粗、底色淡染強調色。改過未保存的資料夾標一個點。Ctrl＋點選可加選或取消、Shift＋點選選取一段，選了兩個以上時清單上方出現「套用版面…」「清除專屬版面」「取消選取」，一次改所選資料夾的專屬版面（沒有記錄的資料夾略過）。上方可切換「全部／只看專屬／只看未保存」，底部「N 處尚未保存」可按，按了只列出改過的資料夾（R-444）。
- **預覽**：清單下方用實際卡片畫出所選資料夾套用後的樣子；多選時改畫所選的資料夾（最多 3 個）。卡片寬度填滿預覽區、字不縮放，預覽區高度跟著卡片；資料夾清單至少保留約 5 列，卡片更高時只有卡片部分捲動，預覽標題列固定不動（R-444）。標題旁的箭頭可收合，記在這台電腦；沒記過時，視窗寬度不到 960 就先收合；這時規則欄疊在清單上方，視窗高度內仍要看得到底部的取消與保存（R-497）。卡片模式的預覽標題旁有「編輯卡片版面」（沒有未保存變更時），在編輯器打開所選資料夾套用的卡片版面；從這裡打開並保存不會改變預設版面，除非在編輯器裡改選了別的方案（R-444）。
- **卡片／詳情**（R-409）：視窗上方切換設定卡片或詳情版面，兩邊的規則形狀相同、各自的草稿在切換時保留，保存一次寫入兩邊。右側的預設版面可選「內建詳情」；左側標題改為「依類型」與「依層級」。右側模式的預覽畫出所選資料夾的右側，「編輯詳情版面」（沒有未保存變更時）在編輯器打開它；資料夾列的「⋯」選單有「另做一份給這個資料夾…」：複製它目前的右側（沒有時用內建的）、以資料夾名稱命名、指定給它、連同未保存的變更一起保存，並打開編輯器。
- **清單範圍**（R-483）：清單從瀏覽中的資料夾開始；清單上方的麵包屑（專案頂層到該資料夾）可點任何一層，清單就改從那一層開始（預設展開兩層，選取與多選不在新範圍的取消），不關視窗、不動主畫面的位置；草稿與未保存計數不受影響；關閉再開仍從瀏覽中的資料夾開始。
- **資料夾設定**：「類型與版面」只顯示這個資料夾目前的卡片與詳情版面及其來源，按「卡片版面配置…」或「詳情版面配置…」開啟本視窗，清單從這個資料夾開始。
- 底部顯示幾處未保存（卡片與右側合計）；取消放棄、保存一次寫入。

## 資料

專案記錄的 `layoutRules`（暫定）：`{ card?, panel? }`，各是 `{ types?, levels?, folders? }`：`types` 以資料夾類型為鍵、`levels[0]` 是第 1 層、`folders` 以資料夾 ID 為鍵，值都是版面 ID；`card` 指向卡片版面（`layoutPresets`），`panel` 指向詳情版面（`panelPresets`）。專案格式 v1 的 `kindLayouts`、`folderLayouts`、`bookPresetId`、`folderBookPresets` 與內容模板在升到 v2 時換算成這些規則，見 [DATA_FORMAT](DATA_FORMAT.md)。
