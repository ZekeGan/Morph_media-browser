# 版面配置規則

最後確認：2026-11-17（R-409）

一個專案的卡片版面與右側版面，都由同一套規則決定，在同一個「版面配置」視窗設定。程式：[layoutRules.ts](../shared/layoutRules.ts)。

## 決定順序

每個資料夾依序找第一個成立的規則（卡片與右側各自一套，形狀相同）：

1. **資料夾專屬**：這個資料夾自己指定的版面。
2. **作品依類型**：資料夾算作品時（判斷同「所有作品」，見 [WORKSPACE_REVISION](WORKSPACE_REVISION.md)），用它類型（遊戲、書籍、音樂、影片、一般）的版面。作品裡的作品照樣用自己類型的版面，所以同一類型在任何深度都長一樣。
3. **一般資料夾依層級**：不是作品的資料夾，用它所在層級的版面；第 1 層是專案根目錄底下那一層。
4. **預設版面**：以上都沒有（含沒設定的層級、之後新建出的更深層、根目錄本身），用專案的預設版面。

**右側版面**（R-409）的規則形狀相同，但依頁面的類型決定，不看資料夾算不算作品：資料夾專屬 → 該類型的版面 → 所在層級的版面 → 右側預設版面；都沒有時顯示該類型的內建右側（書籍是左側封面加卡片欄位，其他類型不顯示）。編輯器保存時選中的右側版面成為該類型的版面；為單一資料夾開啟時不改類型的版面。

規則指向的版面被刪除時跳過該條，從下一條繼續；刪除版面時同時從所有規則移除。

## 版面配置視窗

- 入口：瀏覽工具列的按鈕，文字是目前資料夾套用的版面；旁邊的「編輯版面」按鈕不變（編輯版面內容）。
- **左側規則**：預設版面（沒有其他規則時使用）、作品依類型（遊戲、書籍／漫畫、音樂、影片、一般）、一般資料夾依層級（第 1 層到目前最深一層）。每條規則下方寫它目前套到幾個資料夾；沒設定的選單顯示「沿用預設（版面名稱）」。
- **右側資料夾清單**：目前資料夾與底下的資料夾，用縮排表示層級，可展開、收合與搜尋；預設展開兩層。每列有版面選單與來源（類型、層級、預設、專屬，左側色條同色）：沒指定時選單顯示依規則套到的版面，選一個就成為此資料夾專屬，旁邊的 ✕ 清除。改過未保存的資料夾標一個點。
- **預覽**：清單下方用實際卡片畫出所選資料夾與同一層前幾個資料夾套用後的樣子。
- **卡片／右側**（R-409）：視窗上方切換設定卡片或右側版面，兩邊的規則形狀相同、各自的草稿在切換時保留，保存一次寫入兩邊。右側的預設版面可選「內建右側」；左側標題改為「依類型」與「依層級（類型沒有設定時）」。右側模式的預覽畫出所選資料夾的右側，「編輯右側版面」（沒有未保存變更時）在編輯器打開它；資料夾列的「⋯」選單有「另做一份給這個資料夾…」：複製它目前的右側（沒有時用內建的）、以資料夾名稱命名、指定給它、連同未保存的變更一起保存，並打開編輯器。
- **資料夾設定**：「外觀」只顯示這個資料夾目前的卡片與右側版面及其來源，按「卡片版面配置…」或「右側版面配置…」開啟本視窗，清單從這個資料夾開始。
- 底部顯示幾處未保存（卡片與右側合計）；取消放棄、保存一次寫入。

## 資料

專案記錄的 `layoutRules`（暫定）：`{ card?, panel? }`，各是 `{ types?, levels?, folders? }`：`types` 以資料夾類型為鍵、`levels[0]` 是第 1 層、`folders` 以資料夾 ID 為鍵，值都是版面 ID；`card` 指向卡片版面（`layoutPresets`），`panel` 指向右側版面（`panelPresets`）。專案格式 v1 的 `kindLayouts`、`folderLayouts`、`bookPresetId`、`folderBookPresets` 與內容模板在升到 v2 時換算成這些規則，見 [DATA_FORMAT](DATA_FORMAT.md)。
