# 需求清單

只放還沒結束的需求；完成並查收的需求刪除（內容在 [CHANGELOG](../CHANGELOG.md) 與 git 歷史）。核定規則由規格持有，按 [任務索引](README.md#按任務定位) 選讀；流程規則在 [CLAUDE.md](../CLAUDE.md)。`pnpm status` 依本頁印出狀態區塊。

**格式**：`- **R-編號** 標題 ｜大小｜風險｜資料影響｜領域：id（見 [areas.json](areas.json)）｜依賴：R-…｜取代：…`，下一行縮排寫補充（可省略）。

- **大小**：小／中／大。
- **風險**：一般／資料寫入／安全邊界（後兩者提交前獨立審查，同批合併審一次）。
- **資料影響**：無／設定（專案或本機設定）／新增欄位（選用，不升格式；畫面查收前標「暫定」）／改結構（升格式，附升級步驟、舊格式樣本與測試，需核定）。
- **狀態**就是所在的章節；編號從 R-201 起，不與歷史 R／T／UI-R 提案混用。

## 發行前關卡

- **R-SIGN 程式碼簽章**（發布正式版 1.0.0 前必做，到時提醒使用者）：申請 SignPath Foundation 開源專案免費簽章（GitHub Actions 建置、SignPath 簽 Morph.exe、安裝檔、解除安裝程式與可攜版），打包流程改到 GitHub Actions，簽好的檔案附在 Release；同版恢復頁面程序沙箱（C-149 的 Beta 例外隨版本號自動結束，確認後刪掉那段程式與本項）。背景：未簽章的 Morph.exe 會被卡巴斯基注入 DLL，沙箱裡的頁面程序因此中止。

## 已知限制（不是需求）

每條行尾標「（領域：id｜確認：日期）」；該領域程式改動後 `pnpm stale` 會點名重看，首包大小由它和最近一次建置比對。

- 卡片上沒有直接編輯；編輯在資料夾設定，每個欄位各自寫入。（領域：cells、panel｜確認：2026-11-25）
- 窄版遊戲頁工具列（< 620px 篩選改為圖示選單）沒有自動化測試，只用截圖確認過寬版（game-actions-ui 的 620px 只檢查動作編輯器）。（領域：game｜確認：2026-11-25）
- 聲卡實際輸出、滑鼠側鍵實體裝置、其他平台與 Mac 原生啟動不在查收範圍；真實網站登入、遊戲／媒體變體需樣本，未知遊戲保留人工 ROOT／not-game，不重掃或清理真實收藏。（領域：media、detection｜確認：2026-11-27）
- 前端首包約 1.0 MB，啟動時連同預載共約 2.3 MB（主要是 React、Mantine 與五種語言的語系字典約 0.6 MB）；版面編輯器、文件檢視器與閱讀器都是用到才載入（R-503）。影片播放器仍隨背景播放一起在啟動時載入：改成延後載入後，壞掉影片的錯誤說明不再出現，原因未查。語系只載入目前語言要改建置流程，暫不處理。（領域：core｜確認：2026-11-27）
- 大型資料夾：10,000 個檔案首頁 96 筆約 0.2 秒；一次列出全部約 2 秒（介面不這樣呼叫）。檔案清單依大小或日期排序時，第一批要等整個資料夾的大小與時間都讀完才回來（R-492），硬碟或網路磁碟上的大型資料夾會比較慢出現；改看別的資料夾時這次讀取會停止，切回 1 分鐘內不重讀（R-504）。1 分鐘內檔案內容變大變小但沒有增刪檔名時，排序可能還照舊的大小，顯示的大小是新的。（領域：files、media｜確認：2026-11-27）
